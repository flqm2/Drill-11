# 자동 달리기 기능 — AI 개발 요구사항

## 1. 문서 목적과 적용 범위

이 문서는 같은 폴더의 `PRD.md`와 사용자가 추가로 확정한 세부 규칙을 AI가 구현할 수 있도록 구체화한 개발 기준이다. 자동 달리기 요구사항을 기존 프로그램에 통합하는 데 필요한 동작, 상태 전이, 호환 조건과 완료 기준을 정리한다.

기준 코드는 `main.py`, `boy.py`, `grass.py`이다. `prompt` 폴더의 이전 이동 실습 문서와 구분하며, 이번 원문에 없는 기능이나 수치를 새로운 요구사항으로 추가하지 않는다.

## 2. 핵심 요구사항

| 항목 | 요구사항 |
| --- | --- |
| 진입 조건 | 소년이 `IDLE` 상태일 때 `a` 키를 누르면 즉시 `AUTO_RUN` 상태로 전환한다. |
| 자동 이동 | 오른쪽으로 이동을 시작하고 화면 양 끝에 닿으면 반대 방향으로 이동한다. 추가 키 조작 없이 왕복을 계속한다. |
| 이동 속도 | `AUTO_RUN`의 이동 속도는 기본 `RUN`의 2배이다. |
| 표시 크기 | `AUTO_RUN`에서는 소년의 가로·세로 표시 크기를 기본 크기의 1.5배로 확대한다. |
| 자동 종료 | `AUTO_RUN` 진입 후 5초가 지나면 원래 `IDLE` 상태로 복귀한다. |
| 입력에 의한 취소 | `AUTO_RUN`에서 좌우 방향키를 누르면 자동 달리기를 취소하고 기본 `RUN`으로 전환한다. 상하 입력은 제외한다. |
| 조건 우선순위 | 좌우 방향키 입력과 5초 만료가 겹치면 방향키 입력을 우선하여 `RUN`으로 전환한다. |
| 구현 구조 | 자동 달리기는 개별 상태 클래스를 추가하여 구현한다. |
| 시각 자료 | 각 상태의 관계를 나타내는 상태 다이어그램을 이미지 파일로 생성하고, 한국어로 작성한다. |
| 개발 이력 | 점진적으로 개발하고 한국어 제목과 설명을 포함한 커밋을 최소 15회 남긴다. |
| 기존 코드 호환 | 기존 `main.py`의 실행 흐름 및 연결된 기존 상태 동작과 호환되어야 한다. |

## 3. 상태별 동작과 전이

### 3.1 IDLE → AUTO_RUN

- `IDLE`에서 `a` 키를 누르면 대기 시간 없이 즉시 자동 달리기를 시작한다.
- 진입 시 자동 달리기 시작 시각을 기록한다. 5초는 이 진입 시점을 기준으로 측정한다.
- 오른쪽 이동으로 시작하며, 기본 `RUN` 속도의 2배와 기본 표시 크기의 1.5배를 적용한다.
- `a` 키를 계속 누르거나 다른 키를 반복 입력하지 않아도 자동 이동이 유지되어야 한다.

### 3.2 AUTO_RUN 유지

- 매 갱신 시 자동 이동과 해당 상태의 표시를 처리한다. 화면 오른쪽 끝에 닿으면 왼쪽으로, 왼쪽 끝에 닿으면 오른쪽으로 방향을 바꾼다.
- 기본 `RUN`의 2배 속도와 가로·세로 1.5배의 표시 크기를 유지한다.
- 좌우 방향키 입력을 먼저 확인하고, 입력에 의한 취소가 없을 때 5초 만료를 확인한다. 상하 방향키는 자동 달리기의 이동·취소 입력으로 처리하지 않는다.

### 3.3 AUTO_RUN → IDLE

- 자동 달리기 시작 후 5초가 경과하고 같은 갱신 시점에 좌우 방향키 누름이 없으면 `IDLE`로 전환한다.
- 자동 이동을 종료하고 자동 달리기에 사용한 속도·확대 효과가 다음 상태에 남지 않도록 정리한다.
- 복귀 후에는 기존 `IDLE` 동작을 따른다.

### 3.4 AUTO_RUN → RUN

- 자동 달리기 중 좌우 방향키 누름을 받으면 5초 만료를 기다리지 않고 `RUN`으로 전환한다. 5초 만료와 겹쳐도 방향키 입력을 우선한다.
- 전환을 일으킨 방향키 입력이 기본 달리기 처리로 이어지도록 한다.
- 자동 이동과 확대 효과를 종료하고 기본 `RUN`의 속도와 표시 크기를 사용한다.
- 자동 달리기 타이머가 취소 후 `RUN`을 강제로 `IDLE`로 바꾸지 않도록 한다.
- 전환 이후 키 누름·해제 동작은 기존 `RUN`의 입력 규칙을 따른다.

| 현재 상태 | 조건 | 다음 상태 | 전환 결과 |
| --- | --- | --- | --- |
| `IDLE` | `a` 키 누름 | `AUTO_RUN` | 즉시 오른쪽 이동 시작, 속도 2배, 크기 1.5배, 5초 측정 시작 |
| `AUTO_RUN` | 별도 입력 없이 5초 미만 경과 | `AUTO_RUN` | 자동 이동과 확대 표시 유지 |
| `AUTO_RUN` | 화면 끝에 도달 | `AUTO_RUN` | 이동 방향을 반대로 전환 |
| `AUTO_RUN` | 진입 후 5초 경과, 좌우 방향키 누름 없음 | `IDLE` | 자동 이동 종료, 기본 표시 복원 |
| `AUTO_RUN` | 좌우 방향키 누름 | `RUN` | 시간 만료보다 우선하여 자동 달리기 취소, 기본 달리기 처리 |

## 4. 기존 코드와의 호환 및 구현 조건

- 현재 `main.py`는 이벤트를 `boy.handle_event(event)`로 전달하고, 월드 반복문에서 `update()`와 `draw()`를 호출한다. 이 호출 구조와 호환되도록 구현한다.
- 기존 `Boy`에는 `IDLE`, `SLEEP`, `RUN` 상태가 있으며 `transitions.Machine`으로 상태를 관리한다. 자동 달리기를 연결하면서 기존 상태의 동작과 전이를 유지한다.
- 자동 달리기는 별도 상태 클래스로 구현한다. 상태 이름만 추가하거나 기존 메서드에 분기만 추가하는 것으로 개별 상태 클래스 요구사항을 대체하지 않는다.
- 별도 클래스가 자동 달리기의 진입, 갱신, 종료 처리를 담당하도록 구성하되 기존 상태 관리 방식 및 `Boy`의 외부 호출과 연결한다.
- 속도와 표시 크기는 자동 달리기 상태의 속성으로 구분하여, 종료 시 기본 상태로 복원할 수 있게 한다.

## 5. 추가로 확정한 세부 규칙

다음 항목은 사용자가 추가로 지정한 기준이며, 자동 달리기 구현과 검수에 적용한다.

- **자동 이동 방향 규칙:** 자동 달리기에 진입하면 오른쪽으로 이동을 시작한다. 화면 양 끝의 벽에 닿으면 반대 방향으로 이동하여 좌우 왕복을 이어간다.
- **속도와 확대 수치:** 이동 속도는 기본 `RUN`의 2배, 표시 크기는 기본 가로·세로 크기의 각각 1.5배로 설정한다.
- **방향키 범위:** 좌우 입력만 처리한다. 상하 입력은 이동 및 자동 달리기 취소 대상에서 제외한다.
- **조건 충돌:** 좌우 방향키 누름과 5초 만료가 같은 갱신 시점에 발생하면 방향키 입력을 우선하여 `RUN`으로 전환한다.
- **IDLE에서 a 입력:** `IDLE`에서 `a` 키를 누르면 곧바로 `AUTO_RUN`으로 전환한다. 추가 설명의 제목은 “IDLE 외 상태”였으나 본문은 `IDLE`을 지정했으므로, 다른 상태에서의 `a` 입력 동작은 별도로 확정되지 않은 것으로 남긴다.

## 6. 상태 다이어그램 산출물

- 구현 시 전체 상태 관계를 확인할 수 있는 이미지 파일을 생성한다.
- 기존 `IDLE`, `SLEEP`, `RUN`과 새 `AUTO_RUN` 상태 및 실제로 구현한 전이를 표현한다.
- 상태 설명과 전이 조건은 한국어로 작성한다. 예: `대기`, `자동 달리기`, `a 키 누름`, `5초 경과`, `좌우 방향키 누름`, `벽에 닿으면 방향 반전`. 좌우 방향키 입력이 시간 만료보다 우선함을 표시한다.
- 다이어그램은 실제 코드의 상태 전이와 일치해야 한다. 이미지 형식과 파일명은 원문에서 지정하지 않았다.

## 7. 개발 진행과 완료 기준

기존 구조 확인 → 개별 자동 달리기 상태 클래스 추가 → 진입 및 자동 이동 연결 → 속도·크기 적용 → 5초 복귀 및 입력 취소 처리 → 호환 동작 확인 → 한국어 상태 다이어그램 작성 순으로 점진적으로 진행한다.

개발 과정에서 최소 15회의 의미 있는 커밋을 남긴다. 각 커밋은 한국어의 간단한 제목과 변경 내용을 설명하는 본문으로 구성한다.

| 검수 항목 | 완료 기준 |
| --- | --- |
| 자동 달리기 진입 | `IDLE`에서 `a` 키를 누르면 즉시 `AUTO_RUN`으로 전환되어 오른쪽 이동을 시작한다. |
| 자동 이동 유지 | 별도 키 조작 없이 이동하며 화면 양 끝에 닿으면 반대 방향으로 왕복한다. |

| 시간에 따른 복귀 | 좌우 방향키 누름이 없으면 진입 후 5초가 지났을 때 자동 이동이 끝나고 `IDLE`로 돌아간다. |
| 방향키 취소 | 자동 달리기 중 좌우 방향키를 누르면 기본 `RUN`으로 전환된다. 상하 입력으로는 취소되지 않는다. |

| 종료 시 정리 | 복귀·취소 후 자동 달리기의 속도, 확대 효과와 타이머가 다음 상태에 영향을 주지 않는다. |
| 상태 클래스 | 자동 달리기를 담당하는 개별 상태 클래스가 존재하고 실제 동작에 사용된다. |

| 상태 다이어그램 | 한국어로 작성한 이미지 파일이 존재하며 실제 상태 전이와 일치한다. |
| 커밋 이력 | 단계별 개발 커밋이 15회 이상이며 한국어 제목과 설명을 포함한다. |
