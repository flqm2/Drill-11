IDLE 상태에서 a키를 누르면 소년은 자동 런 상태로 변경되어 별 다른 키 조작 없이도 계속 좌 우로 이동하게 된다.

AUTO RUN 상태에서는 소년의 속도가 빨라지며, 크기가 확대되어 있어야 한다.

자동 런 상태는 5초후 원래 IDLE 상태로 돌아가게 된다.

자동 런 상태에서 방향키를 누르면 자동 런이 취소되고 기본 런상태로 변경된다.

Auto Run의 경우 개별적인 상태 클래스를 추가해서 구현해야한다.

생성 시 각 상태들의 상태 다이어그램을 이미지 파일로 생성한다.

상태 다이어그램은 한국어로 작성한다.

개발은 점진적, 단계별로 진행하며, 최소 15회 이상의 커밋을 남긴다.
커밋은 한국어로 작성하며 간단한 제목과 설명으로 구성한다.

반드시 기존 main.py에서 작성된 상태와 호환되도록 작성한다.
